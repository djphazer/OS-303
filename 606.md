# OS-606 Firmware

Replacement for the TR-606 CPU, using AT90USB1286 MCU. Built with PlatformIO - a Python-based toolchain.

## Updates

Firmware updates using .SYX files should work automatically - send them with about 150ms delay between messages. The first 4 step LEDs will cycle as it writes new pages, and then it will reboot.
