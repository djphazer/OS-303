# Open Source x0x Firmwares

Here lie three legendary music machines, revived with modern microcontrollers.

To build all: `pio run`

* .hex files are for programming the chip directly, including bootloader. Fuses must be set separately.
* .syx files are for app updates via MIDI.

[**OS-303**](303.md)

`pio run -e app303`

[**OS-606**](606.md)

`pio run -e app606`

[**OS-808**](808.md)

`pio run -e app808`
